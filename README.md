# Башни против Мемов

Мем-башни против забавных монстров — HTML5-игра в жанре **tower defense** для платформы **Яндекс Игры**.

Расставляйте и прокачивайте пушки на клетках, стройте оборону вдоль извилистой тропы и не пропускайте мем-монстров к базе. 10 уровней с уникальными картами + бесконечный режим, ящики с пушками разной редкости, отряд из 4 пушек, Книга мемов. Интерфейс на русском и английском; в английской версии игра называется «Towers vs Memes».

Ссылка: https://yandex.ru/games/app/556105?debug-mode=16&draft=true&lang=ru

## Технологии

Чистый HTML + CSS + JavaScript (ES6), рендеринг на `<canvas>`. Без сборщиков и зависимостей. Вся графика рисуется кодом, звук — через Web Audio API. Единственная внешняя зависимость — SDK Яндекс Игр (`/sdk.js`); игра корректно запускается и без него.

## Запуск локально

Достаточно открыть `index.html` в браузере. Либо отдать папку любым статическим сервером:

    python -m http.server 8080
    # затем открыть http://localhost:8080

## Управление

- **Десктоп:** мышь — выбрать пушку внизу, клик по зелёной клетке (поставить); клик по своей башне — улучшение / починка / продажа. Клавиши: `1–4` выбор пушки, `Пробел` — запуск волны, `F` — ускорение x1/x2/x5, `Esc` — пауза.
- **Мобильные:** тап по пушке, затем тап по клетке; тап по башне — меню; кнопка «В бой» запускает волну. Только альбомная ориентация: если держать телефон или планшет вертикально, игра встаёт на паузу и просит повернуть устройство.

## Структура

    index.html        точка входа (подключает /sdk.js)
    css/style.css     стили
    js/audio.js       звук (Web Audio API)
    js/maps.js        генерация карт уровней
    js/game.js        логика, рендер, ввод, интеграция SDK
    assets/enemies/   опциональные PNG-спрайты (по умолчанию рисуется вектор)
